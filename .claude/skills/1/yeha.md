# 예하(YEHA) 아카이브 — 캐릭터, 세계관, 지금까지 만든 영상 전부

감독과 함께 만든 예하 관련 모든 것. 새 영상을 짤 때 이 파일로 예하의 설정, 이미 한 것, 반응 좋았던 것, 실패한 것을 확인한다.

## 1. 캐릭터 기본

- **이름**: 예하(YEHA). 프롬프트에서는 항상 `YEHA`로 표기.
- **성별/외형**: 실사 여성. 외형은 `@Image 1`(얼굴, 헤어), 의상은 `@Image 2`. 레퍼런스는 기본 두 장만.
- **성격/톤**: 차갑고 무표정, 귀찮다는 듯 여유로움. 압도적으로 강하지만 힘을 들이지 않음. 결정적 순간에만 눈빛이 날카로워짐.
- **시그니처 패턴**: 압도적 위협 → 귀찮다는 태도 → 한 방 → 정적 → 일상적 대사/행동으로 마무리.
- **대가 없음**: 능력을 써도 힘들어하거나 코피 흘리지 않음(감독 지시).
- **악역 반전**: 액체 괴물 시리즈에서는 검은 눈으로 사악하게 씨익 웃는 다크 히어로/괴물 면모.

### 실패했거나 감독이 별로라고 한 것
- **취권**: 유치해짐. 진지한 결투 톤이 맞음.
- **좀비 취권**: 개그 과다.
- **헬기 낙하 → 착지 → 음속 → 곡예 → 슬로우존**: 아이디어를 계속 덧붙여 망함("갈수록 별로").
- **고철 갑옷**: 고철이 볼품없음 → 정제된 갑옷으로 고쳤으나 결국 "별로".
- **형식 비틀기 아이디어**(고양이 고정카메라, 플래시 스트로브 등): "굉장히 별로". 액션을 직접 보여줘야 함.
- **커플 사진 코믹**: 시도함(남자가 사진을 이상하게 찍고 가방 툭 → 강에 빠짐).
- **액체 연구소 습격(변신 6개)**: 너무 많은 변신으로 망함. 손가락 총만 잘 나옴.

## 3. 액체 괴물 시리즈 정리 (세계관)

- 예하는 비밀 연구소의 **살아 있는 검은 액체**와 결합. 기준 질감은 페로플루이드.
- 형태: 전신 덮기(머리카락 완전히 덮음, 얼굴만 노출 또는 얼굴 없는 형체), 촉수, 손바닥 방패, 액체 검, 철퇴, 윙슈트, 큰 손, 액체 늑대, 복어 가시, 방울 → 얼굴 삼키기, 스며들기, 손가락 총(**가장 잘 나옴**), 거미 다리 촉수, 괴물 턱, 괴물 눈.
- 이후 **초록 독 액체**를 흡수 → 검은 몸 아래로 초록이 피처럼 흐르는 혈관.
- 최근 기획: **CCTV 1화**(수갑 찬 예하가 고개를 옆으로 꺾어 CCTV를 응시 → 괴물 턱이 카메라를 삼킴 → 문 열면 액체가 밀려나옴 → 경찰 등 뒤에서 솟음 → 벽·천장을 타며 회피 → 복도 전체 가시 → 암흑 속 괴물 눈). 검열 대응으로 **제압(pin)만** 하는 버전.
- 대안 콘셉트로 제안된 것: 액체 서부극 결투(붉은 액체 라이벌), 엘리베이터 호러, 다리 붕괴 구조, 액체 웅덩이 이동.

## 4. 감독 작업 방식 메모

- 감독이 직접 스토리보드를 주면 **그대로** 따른다. 임의로 설정을 덧붙이지 않는다.
- 수정 요청 시 **항상 전체 프롬프트를 합쳐서** 전달.
- 길이 제한은 기본 없음(한 번만 10,000자로 요청한 적 있음, 평소엔 제한 없이).
- 결과 영상은 0.5초 간격 프레임으로 검토해서 시간대별로 피드백.
- 반응이 좋은 방향: **실제 물질이 미친 듯이 움직이는 능력 + 직접 보여주는 액션**, 강한 훅, 실사 질감.
- 싫어하는 것: BGM/앰비언트, 불릿타임 남발, CG 같은 질감, 유치한 개그, 모호한 괴물, 등지고 싸우기, 화염 나는 손가락 총.
